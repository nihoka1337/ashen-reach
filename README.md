# Пепельный Предел

Небольшая текстовая RPG в браузере. Пепел стирает имена, а ты пытаешься сохранить своё: четыре города, опасные земли, боссы, рейд, лут, торговцы и кодекс.

## Запуск

Самый простой способ — двойной клик по `start.bat`: он поднимет локальный сервер на `http://127.0.0.1:8123` и откроет игру в браузере.

Можно открыть и напрямую `index.html`. Тогда звук, canvas и сохранение тоже работают, но в некоторых браузерах localStorage для `file://` может быть ограничен — в этом случае прогресс не сохранится.

Требуется Python 3 (только для `start.bat`).

## Управление

- `1–4` — умения класса в бою;
- кнопка `Автобой` — бой сам использует умения и лечится, когда здоровье падает ниже трети;
- `Отступить` — попытка сбежать из обычного боя (70%); из боя с боссом или рейда отступить нельзя;
- в инвентаре нажми на вещь, чтобы надеть, снять или продать её;
- у торговцев нажми на товар, чтобы посмотреть характеристики и сравнить с надетым;
- прогресс автоматически сохраняется в браузере.

## Что внутри

- 3 класса с разными характеристиками и наборами из 4 умений;
- 4 города, 4 локации, 4 босса и трёхволновой рейд «Сердце Хмари»;
- 17 видов противников, способности, кровотечение/яд/огонь/оглушение;
- 7 слотов экипировки, 5 редкостей, случайные аффиксы, лут с мобов и боссов;
- 8 торговцев, 8 НПС с диалогами, подарками и записями в кодексе;
- доска контрактов с наградами;
- 15 записей лора, открывающихся через путешествия, разговоры и победы;
- canvas-сцена боя с анимациями, частицами, цифрами урона и экранной тряской.
